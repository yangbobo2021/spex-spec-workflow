# Skill maintenance

- This repository owns the `spex-spec-workflow` Skill and its references, not the user's application SPEC.
- Preserve the user's requested scope and existing Skill behavior unless a change is requested.
- Validate Skill structure and affected acceptance scenarios; ordinary documentation changes do not require the whole Docker suite.
- Use Git commits and tags for version history. Do not create routine backup copies or version folders.
- Preserve uncommitted work. Commit and push when authorized by the current task.
